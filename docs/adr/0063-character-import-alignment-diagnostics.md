# ADR 0063 — Shared character profiles, alignment and headless diagnostics

Status: Proposed. Owner: Codex. Base main `62a9b30`. Batch items 02.01, 02.02c, 02.02d.

Character authored conventions are right-handed +Y up, metres, forward -Z, feet at the actor origin. Introduce owned `character` APIs for the existing version-1 profile parser, role resolution, visual fitting/yaw, explicit capsule/camera dimensions and executable inspection. Foot calibration is shared with the terrain controller, including independent direct legs and rest-pose verification. The sandbox and headless `lyko inspect-character` use the same parser, selection, alignment and validation; the engine never depends on sample headers.

Preserve existing profile semantics: `height` changes visual fitting only. Optional `yaw_degrees` (-180..180) rotates the model about +Y and recentres its feet/bind bounds. Optional `capsule_height`, `capsule_radius`, `eye_height` explicitly configure collision/camera dimensions; absent settings preserve current defaults. Radius must leave a positive cylinder and eye height must lie inside the standing height. Visual yaw applies consistently to rendering and terrain IK world/model conversion. No skeleton/clip/physics source data is rewritten.

Inspection validates mesh/skeleton/clip/skin array contracts and requested clips/roles without a GPU. It reports finite bind dimensions, applied alignment, capsule/camera dimensions, clip information and structured rig prerequisites. Comparison diagnostics declare the initial retarget subset: unique named joints, one root, unit rest scales, nonzero finite parent links, full name mapping and matching parent relationships, local rest directions and rest axes up to a root basis rotation. Unsupported rigs produce explicit issues rather than a retarget claim. Playable imports may remain valid while this narrower retarget subset is unsupported. Actual pose transfer is batch item 02.10, not this diagnostic step.

Profile input stays bounded to 64 KiB/depth 8 with per-object duplicate/unknown-key rejection and transactional decode. Headless inspection returns machine-readable JSON and nonzero on invalid assets/profiles, and never opens a window. Output must not replace input files. Tests cover malformed input, alignment and capsule boundaries, rig comparisons, generated glTF CLI inspection and sandbox/profile/foot-IK compatibility. Full native and hosted matrix precedes merge. Hardware/subjective acceptance remains deferred.
