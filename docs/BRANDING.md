## Visual reference

- Faceted gold wolf emblem.
- Angular metallic hexagonal frame.
- Uppercase LYKOWARE wordmark.
- Black background with gold and metallic grey accents.

These describe the supplied artwork, not a complete typography or colour specification. Exact brand colour values and the original typeface have not been established.

Use this as the reference for future engine presentation, icons and splash screens. Keep the original asset intact; save any later derivatives separately. This JPEG has an opaque background; transparent, vector, icon and monochrome variants are not supplied or generated here.

The logo is an engine brand asset. It does not impose an art style on games built with Lykoware. Adding it to the README does not add a runtime splash screen or change the engine implementation.
