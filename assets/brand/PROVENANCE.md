# Provenance — Lykoware brand logo vector set

- **Source concept:** `lykoware-concept.jpg`, an AI-assisted concept image approved by Joshua Kingsworth (Lykoleon Studios). The concept itself is not committed.
- **Method:** all vectors were **hand-authored** as SVG polygons (coordinates written by hand in `gen.py`), using the concept only as a visual reference. No auto-tracing or image-to-vector conversion.
- **Tools (all free/open source):** Python 3, fontTools (text-to-path, variable-font instancing), CairoSVG (rasterising), Pillow (ICO, preview sheet).
