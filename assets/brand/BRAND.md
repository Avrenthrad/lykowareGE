# Lykoware Brand Assets

## Colours
| Role | Hex |
|---|---|
| Gold (primary / highlight) | `#F2B630` |
| Gold (mid facet) | `#D99A1E` |
| Gold (shadow facet) | `#A8700F` |
| Steel frame | `#8A8D93` |
| Eye / detail dark | `#1A1408` |
| Recommended dark background | `#0D0D0F` |
| Mono | `#FFFFFF` / `#000000` |

## Clear space
Keep clear space on all sides equal to **1/4 of the hexagon emblem height** (the "H/4" rule). For the wordmark alone, use the cap height of the letters.

## Minimum sizes
- Full icon (`lykoware-icon.svg`): 64 px / 12 mm.
- Simple icon (`lykoware-icon-simple.svg`): use for 48 px and below (favicons, taskbar). Down to 16 px.
- Stacked logo: 160 px wide. Horizontal logo: 200 px wide. Wordmark: 96 px wide.

## Which file where
| File | Use |
|---|---|
| `lykoware-logo.svg` | Primary stacked logo: splash screens, title cards, docs covers |
| `lykoware-logo-horizontal.svg` | Headers, banners, website nav, README |
| `lykoware-icon.svg` | App icon / avatar at 64 px+ |
| `lykoware-icon-simple.svg` | Favicon, small UI icons, ≤48 px |
| `lykoware-wordmark.svg` | Text-only placements |
| `*-white.svg` / `*-black.svg` | Single-colour use on photos, dark/light, print, embossing |
| `png/` | Raster exports (icons 16–1024 px, logos 1024/2048 px wide) |
| `lykoware.ico` | Windows executable / favicon (16–256 px) |
| `preview.png` | Overview sheet on light and dark |

Gold on dark (`#0D0D0F`) is the preferred presentation. Do not recolour, stretch, rotate, add effects, or re-typeset the wordmark.

## Typography & licence
The wordmark is **Orbitron** (SemiBold, wght 600, letter-spacing 0.10 em) converted to outlines; no font is needed to display the SVGs.

## Source
All artwork is hand-authored polygons generated by `source/gen.py` + `source/build.py` (Python, fonttools, cairosvg, Pillow). Approved concept: `lykoware-concept.jpg`.

## Regenerating the PNGs (scripts/README note)
Only the SVGs, `lykoware.ico`, `png/lykoware-icon-512.png` and `preview.png` are committed; the other PNG sizes and the zip are generated output. To regenerate:
```sh
pip install fonttools cairosvg pillow
cd <brand workspace>/source   # generator scripts kept outside the repo (generated-asset rule); contains gen.py, build.py, orbitron-600.ttf (Orbitron static instance, wght 600)
python3 build.py          # writes ../*.svg, ../png/*.png (icons 16–1024, logos 1024/2048), ../lykoware.ico, ../preview.png
```
Icons ≤48 px are rendered from `lykoware-icon-simple.svg`.
